---
name: 浏览器单次动画时钟
description: React effect 启动逐帧动画时须处理同一浏览器帧内稍早的 RAF 时间戳。
---

在 effect 内用 `performance.now()` 记录开始时间，再使用 RAF 回调时间戳计算已播时长时，须把微小的负值钳制为零；不要把负值误判为播放结束。

**Why:** 同一浏览器帧的 RAF 时间戳可能略早于 effect 的开始时间，曾导致状态已进入点击反应，但只播开头一帧便提前结束。类型检查和纯播放时长测试无法发现此情况。

**How to apply:** 逐帧动画以实际经过时长寻帧，首帧允许零时长；超过总时长终止而不是循环。仅在有意安排未来开始时间的预备动画中，把负时长作为“尚未开始”，不要与“已经结束”混用。
