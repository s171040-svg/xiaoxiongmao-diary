---
name: 行进中的动作过渡
description: 区分随行进播放的转身与需要停止路线的驻留姿势过渡。
---

行进中的姿态过渡（例如爬梯转身）必须让原有路线继续推进；睡觉、躺下等驻留过渡仍可阻止走动。管理路线生命周期时，应依赖“是否阻断移动”的语义，而不是任意过渡方向或帧状态。

**Why:** React 移动 effect 的依赖变化会先清理路线与动画帧。把爬梯转身当成驻留过渡，会在刚开始上楼时取消整条路线，即使素材齐全且加载成功也无法播放完整上楼流程。

**How to apply:** 增加或修改行进过渡时，验证过渡开始、循环与结束不会重启路线；从真实地面走到目的地验证，而不只检查静态素材或独立动画检视。
