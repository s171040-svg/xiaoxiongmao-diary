---
name: GitHub 对象同步的字节一致性
description: 通过 GitHub Git Database API 同步本地源码时，避免文本导出和提交末尾换行造成对象不一致。
---

优先使用正常的 Git 推送。必须经 GitHub Git Database API 上传已有本地提交时，以完整树和提交的对象哈希一致为准；不一致时不能推进远端分支，更不能强制覆盖。

**Why:** 经文本形式导出的一个大源码文件曾与真实 blob 字节不一致；另外，GitHub 创建提交接口不会自动补上本地 Git 提交消息末尾的换行，省略它会改变提交哈希，即使源码树和可见消息都相同。

**How to apply:** 需要精确复现时从真实 Git blob 导出字节并用 base64 上传，保留提交消息的末尾换行和作者时间格式；上传后先比较树与提交对象，再以非强制方式更新分支。不要仅凭文件数、可见文本或上传成功判断源码已完整同步。
