# 小熊猫日记 · 桌面客户端

仓库根目录的 [README](../../../README.md) 有 Windows 安装、运行和打包步骤。这里只记桌宠进程本身的行为。

## 窗口

- Windows：工作区大小的透明无边框窗口，`thickFrame: false`、`roundedCorners: false`，避免系统把透明层画成色块。空白处鼠标穿透。
- 其他系统：右下角一块小房间，方便在没有 Windows 桌面的环境里看动画。拖动小熊猫会移动这扇窗。
- 默认置顶。日记打开时日记窗升到桌宠上面，避免全屏透明层把聊天盖住。托盘可以取消置顶。
- 启动时不抢焦点。

## 交互

- 单击小熊猫：随机暖心短句。
- 双击：显示「今天有什么烦心事呢？」；「说说看」打开日记，「不是」收起气泡。
- 拖动小熊猫可以换位置。Windows 全屏模式下松手后会停住，托盘「继续闲逛」再恢复走动。
- 日记输入文字、附上照片，再点「收好这一页」。收到有效 AI 回应、确认本机保存成功后，等待约两秒收起窗口，小熊猫说「记好啦，我去玩啦～」。
- 右上角关闭、系统关闭或最小化：只收起日记，桌宠继续活动。
- 右键小熊猫或托盘：打开日记、显示小熊猫、置顶、闲逛开关、退出。

## 数据和 AI

- 桌面版使用 Electron 自己的本机浏览器存储。日记、照片和回应不保存到服务器。
- 位置、是否置顶、是否停住，写在用户数据目录的 `pet-settings.json`。
- 文字在点击收好后由主进程发到 `https://api.deepseek.com/chat/completions`。环境变量 `DEEPSEEK_API_KEY` 不暴露给页面。没有密钥时桌宠仍可运行，只是不能完成 AI 回复。
- 照片只作为本机附件，不发送给 DeepSeek。
- 网络、密钥、AI 格式或存储失败时不清空草稿、不收起窗口、不显示虚假的保存成功。

## 打包

`desktop/package-win.cjs` 会带上礼物窗（`gift.html`、`gift-drop.css`、`gift-renderer.js`）和图标。安装包版本来自 `@workspace/panda-journal` 的 `version`。可执行文件名是 `XiaoxiongmaoJournal.exe`，快捷方式名仍是「小熊猫日记」。
