# 小熊猫日记 · 横线平台桌宠

这是现有日记的桌面客户端，不是独立的社交产品。

## 运行

在工作区的 **小熊猫桌宠** VNC 工作流里测试。Replit 的 VNC 是远程 Linux 桌面，桌宠活动在该虚拟桌面上，不会直接覆盖你自己电脑的桌面。

在自己的电脑运行源码：

1. 安装 Node.js 和 pnpm，在项目根目录运行 `pnpm install`。
2. 桌面行走不需要 AI 密钥。仅使用旧的原生 AI 聊天时才需要在操作系统环境变量中配置 `DEEPSEEK_API_KEY`，不要写入源码或安装包。
3. 运行 `pnpm --filter @workspace/panda-journal run desktop:build`。
4. 运行 `pnpm --filter @workspace/panda-journal run desktop:start`。

## Windows 安装包

项目推送到 GitHub 后，可在 Actions 中运行 “Build Windows installer”；成功后下载 `xiaoxiongmao-journal-windows-x64` 构建产物。推送到 `main` 或 `master` 且修改桌宠相关文件时也会自动生成。若在 Windows 本机打包，在项目根目录运行 `pnpm install`，再运行 `pnpm --filter @workspace/panda-journal run desktop:installer:win`。安装包会生成在 `generated-artifacts/windows-installer/`，安装时可选择位置，并创建桌面与开始菜单快捷方式。卸载不会删除本机日记数据。Replit 虚拟桌面不能完成 Windows 安装器的最后生成步骤。

安装包不包含 AI 密钥。需要 AI 聊天时，在 Windows 用户环境变量中设置 `DEEPSEEK_API_KEY` 后重新打开应用。

当前安装包未做代码签名，Windows 可能显示“未知发布者”或 SmartScreen 提示。

开发模式 `desktop:dev` 沿用现有网页服务；在 Replit 内通过共享代理访问，在其他环境默认使用 `http://localhost:21836/`，可通过 `PANDA_JOURNAL_URL` 指定开发页面。

尚未配置自动更新或开机自启动；安装包需在 Windows 本机生成后再验收桌宠交互。

Replit 虚拟桌面已配置 Noto 中文与彩色 emoji 系统字体。自己的 Linux 桌面也需要可用的中文/emoji 字体；macOS、Windows 通常已有相应系统字体。

## 第一版交互

- 启动后宠物站在主显示器底部任务栏上沿，只沿当前横线左右慢走，间歇停留。小白的移动略慢；不再在屏幕空中随机游走，也不同步网页房间的路线。
- 支持的横线只有：底部工作区边界（任务栏上沿）、可见且未最小化的普通窗口最上沿。不会识别标题栏下沿、浏览器工具栏、网页内容或图片里的横线。完全贴住屏幕顶部、没有容纳宠物空间的窗口上沿不作为平台。
- 可以长按把宠物提到窗口上方，松手后垂直落到下方最近的有效横线。不会自动跳上其他窗口，避免打扰办公。
- 支撑窗口关闭、最小化或被其他窗口遮挡后，宠物保持横坐标垂直下落，落到下方窗口上沿；没有其他窗口则落至任务栏。支撑窗口移动时宠物随同移动。
- 单击宠物：出现“要回家吗？”，选择“回家”才切回房间；“再玩一会儿”或 Escape 收起选项。
- 长按约 0.38 秒后可拖动；放开后继续在桌面活动，不误触回家。
- 桌面窗口不放床、浴缸或礼物，不显示待机文字，也不主动弹聊天。
- 原生房间中提供“出门到桌面”按钮。实体出门区域尚未设计，本版先使用按钮。
- 右键或托盘菜单提供回家、显示桌宠、暂停走动、隐藏、退出；房间关闭或最小化后保留桌宠。
- 右键选择“安静模式”后，只在趴着、面向你发呆、睡觉三种姿势中随机停留，每种保持 5–10 分钟，不自主走动。长按仍可拖动，松手或支撑窗口关闭后照常垂直落地，落地后保持安静模式及原休息姿势。再次右键选择“取消安静模式”即恢复横向走动；安静模式不改变网页房间的活动，也不接入尚待安排的甩毛事件。
- Windows 桌宠透明空白区鼠标穿透。只使用主显示器；窗口检测只读取窗口 ID、位置、尺寸和前后顺序，不读取窗口标题或内容，不要求管理员权限。常驻检测进程约每 200ms 更新一次，避免反复启动 PowerShell 编译。检测失败时移除窗口平台并落到任务栏继续活动，自动重试，不将整屏当成障碍。
- “暂停走动”只停止横向走动，失去支撑时仍会落地。系统减少动态效果开启时不自主走动，失去支撑则直接就近落地，避免滞留半空。
- 房间读取当前账号角色后通过可信原生桥同步素材；读取失败或尚未选角时不允许从房间开启桌宠。初次离线启动可显示默认小熊猫预览，不代表已替账号选角。
- Replit Linux 使用有底色的小窗口预览，避免虚拟桌面透明合成黑屏；它不能验证真实 Windows 的全桌面透明、其他应用窗口或多显示器行为。

## 验证与发行边界

基础回归：`node --test artifacts/panda-journal/desktop/pet-lite-model.test.cjs artifacts/panda-journal/desktop/platform-model.test.cjs artifacts/panda-journal/desktop/windows-platforms.test.cjs`。Windows runner 额外实际编译并运行 Win32 检测脚本，检查连续两次窗口快照。

原生窗口回归：`node artifacts/panda-journal/desktop/pet-lite-smoke.cjs`，使用临时资料目录和本地模拟房间，不访问真实账号、聊天或 AI。检查走路位移、鼠标穿透、点击／取消、拖动、角色桥、减少动态效果、回家和重新出门。旧 `smoke.cjs` 针对旧版桌面聊天流程，不是精简桌宠的验收入口。

网页账号和浏览器登录会话不会自动迁移到 Electron。开发版连接已有网页服务；正式发行的登录、共同照料及联网房间仍须配置可访问的服务入口并单独验收，不能仅凭本地 Vite 打包成功宣称公开发行已就绪。安装包必须在 Windows runner 构建并在 Windows 实机核验。

## 数据和 AI

- 桌面版使用 Electron 自己的本机浏览器存储。日记、照片和回应不保存到服务器，也不会自动同步普通浏览器中的日记。
- 旧网页记录不会被迁移、覆盖或删除。桌面客户端与网页版各自的本机记录独立。
- 桌面版的文字在点击收好后直接由主进程发送到 `https://api.deepseek.com/chat/completions`。环境密钥不暴露给渲染页面。
- 照片只作为本机附件，不发送给 DeepSeek；没有宣称 AI 看过照片。
- 浏览器版继续使用现有服务器 AI 接入，不依赖 Electron。
- 网络、密钥、AI 格式或存储失败时不清空草稿、不收起窗口、不显示虚假的保存成功。

## 语音能力边界

“按住说话”使用系统／浏览器 Web Speech 识别能力，把文字放入输入框；松开停止。它不是 DeepSeek 的音频转写服务，某些 Electron/操作系统版本没有可用的语音识别后端。识别可能使用系统／浏览器的联网服务，页面会提示；权限被拒或识别不可用时会明确报错。麦克风没有在 Replit 虚拟桌面里做真人录音验证。没有保存原始音频，也没有把音频上传给小熊猫 AI。
