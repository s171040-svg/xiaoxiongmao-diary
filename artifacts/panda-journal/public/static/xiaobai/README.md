# 小白：首批角色动作

采用用户确认的白色博美形象，保留粗像素、短腿、大眼睛与白色球形尾巴。
原小熊猫素材未覆盖。

## 独立重绘动画

- 待机呼吸/眨眼、行走、睡觉、趴着休息、侧头偷看。
- 小跳、仰躺蹬爪、追球尾巴、趴下撒娇、背身爬行。
- 洗脸搓洗、扑玩、晕乎乎、罐口探头、脏兮兮逃跑。
- 咀嚼竹子，以及香蕉、胡萝卜、鱼、饼干、草莓五套对应食物。

共 21 组循环、152 张新动作帧；另有 17 组姿势过渡，每组 6 张真实重绘帧，可倒放用于起身。
包括站立停步、坐下、趴下、睡觉、受惊、背身、仰躺、提起、偷看、进食、
洗澡、弄脏、湿身、罐口探头、抱着安慰、脏身提起、扑玩准备。

## 共用与尚未独立制作的部分

- 逗猫棒、激光笔、好奇、急刹车共用小白的扑玩动作，不是四套独立动画。
- 垃圾桶进入/退出共用小白的探头过渡；没有重新绘制专属钻桶全流程。
- 被带走归家共用小白晕眩/抱着安慰/起身素材，没有完整专属连续剧情。
- 糖果暂用小白的通用咀嚼；不是独立糖果动画。
- 干净/脏身、清洗/搓洗共用首批小白洗澡动画，未逐个细分泡沫与污渍变化。
- 这些共用动作在动画检视中有提示，不会返回小熊猫身体贴图。

## 选角与发行范围

养成主页登录后第一次确认，服务器永久记录当前账号选择。共同房间的两位成员
共用同一角色；已分别选定不同角色的账号不能借加入房间绕过限制。
原日记和成长进度不清空。角色转化液尚未提供任何接口或领取入口。

本批接入网页房间与成长档案。独立 Electron 悬浮桌宠仍需后续同步角色和验证，
本批没有重新打包 Windows 安装包。

本批普通生成回执合计 79 次额度，未使用 Pro；包括两张未采用的提起姿势草稿。
原始回执保留在项目的生成记录中。
